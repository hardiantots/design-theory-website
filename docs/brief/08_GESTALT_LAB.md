# 08_GESTALT_LAB.md


## Main Module

Gestalt should have one central interactive laboratory plus individual explanations.

---

## Proximity

Display identical objects.

Students change:

```txt
Horizontal Gap
Vertical Gap
```

Observe how grouping changes.

Example:

```txt
● ● ●       ● ● ●
```

versus:

```txt
● ● ● ● ● ●
```

Reflection:

> At what distance did you begin seeing two separate groups?

---

## Similarity

Toggle similarity by:

```txt
Color
Shape
Size
Orientation
```

Students observe which elements appear related.

---

## Closure

Display incomplete geometric forms.

Control:

```txt
Completeness
```

Students can remove portions of a shape while the overall form remains perceptible.

---

## Continuity

Create crossing or flowing paths.

Allow line position or curvature changes.

Explain how visual movement can continue through a composition.

---

## Figure-Ground

Create foreground/background examples.

Controls:

```txt
Contrast
Brightness
Blur
Foreground Color
Background Color
```

Avoid copying copyrighted famous examples exactly.

Create original reversible compositions.

---

## Common Region

Allow containers around several elements to appear/disappear.

---

## Connectedness

Connect items using visible lines.

Observe grouping change.

---

## Common Fate

Animate multiple objects moving in different directions.

Objects moving together should appear related.

Respect:

```css
@media (prefers-reduced-motion: reduce)
```

Provide a static fallback.

---
