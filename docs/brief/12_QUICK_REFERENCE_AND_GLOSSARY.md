## Reference Cards

Example:

### Visual Hierarchy

Ask yourself:

```txt
□ What should viewers see first?
□ What should they see second?
□ Is anything competing unnecessarily?
```

---

### Focal Point

```txt
□ Is there a clear dominant element?
□ Is its dominance intentional?
□ Are other elements supporting it?
```

---

### Typography

```txt
□ Is text readable?
□ Is there enough hierarchy?
□ Are too many fonts competing?
□ Is line spacing comfortable?
```

---

### Color

```txt
□ Is important text readable?
□ Does every color have a role?
□ Is the accent color actually creating emphasis?
```

---

### Layout

```txt
□ Are elements aligned?
□ Are margins consistent?
□ Is spacing intentional?
□ Is there enough negative space?
```
