# Visual Hierarchy

Definition:

> Visual hierarchy is the arrangement of visual elements so viewers can understand which information deserves attention first, second, and later.

Interactive controls:

```txt
Headline Size
Headline Weight
Image Scale
CTA Contrast
Spacing
Alignment
```

Show:

```txt
Possible Viewing Order

1. Headline
2. Image
3. Supporting Message
4. CTA
5. Details
```

Label it:

> Simulated visual hierarchy

Do NOT call it eye tracking.

---

# Focal Point

Teach focal point using:

- scale
- color
- isolation
- position
- contrast
- shape

Demo:

Display multiple similar objects.

Allow one object to become visually dominant.

Question:

> Which element did you notice first?

---

# Contrast

Teach more than color contrast.

Include:

```txt
Size
Weight
Shape
Color
Texture
Direction
Space
Typography
```

Interactive:

```txt
Low Contrast ←────→ High Contrast
```

Explain that too much contrast can also create visual noise.

# Rule of Thirds

Create interactive 3×3 overlay.

Allow objects to move around the composition.

Compare:

```txt
Centered
Rule of Thirds
Intentional Asymmetry
```

Important:

> Rule of Thirds is a compositional guideline, not a requirement.

Support:

```txt
Left
Center
Right
Top
Bottom
Baseline
```

# White Space

Show identical content with:

```txt
Too Tight
Balanced
Excessively Sparse
```

Explain:

> White space refers to intentionally unoccupied visual space, regardless of its actual color.
