## Interactive Hero

Create two versions of the same composition.

### Version A

Weak:

- hierarchy
- spacing
- contrast
- alignment

### Version B

Improved structure.

Use interactive slider or toggle:

```txt
Before ←────●────→ After
```

Do not simply use two static screenshots.

The differences should be generated from the same component data when practical.

## Theory Map

If Future AI City already contains an interactive city or node-map system, adapt it.

Example:

```txt
                VISUAL DESIGN
                     │
        ┌────────────┼────────────┐
        │            │            │
   PERCEPTION   COMPOSITION   COMMUNICATION
        │            │            │
     Gestalt       Grid       Typography
     Contrast      Balance    Hierarchy
```

Avoid heavy WebGL unless already implemented and performant.

A clean SVG/DOM implementation is acceptable.
