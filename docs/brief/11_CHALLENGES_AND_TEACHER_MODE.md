# 11_CHALLENGES_AND_TEACHER_MODE.md

# Challenges

Create visual activities rather than memorization quizzes.

---

## Challenge Types

### Focal Point

Question:

> Which element attracts your attention first?

---

### Gestalt

Question:

> Which objects appear to belong together?

---

### Hierarchy

Task:

> Arrange these pieces of information from most to least important.

---

### Color

Task:

> Select the combination that maintains stronger text readability.

---

### Alignment

Task:

> Fix the layout using a consistent alignment system.

---

## Design Detective

Create compositions containing intentional issues.

Examples:

```txt
Inconsistent Alignment
Weak Contrast
Too Many Font Styles
Poor Spacing
Competing Focal Points
Uneven Margins
```

Prompt:

> Find four possible design problems.

After selection, reveal explanation.

Do not imply there is only one valid redesign.

---

# Teacher Mode

Route:

```txt
/teacher
```

No login.

This is a local presentation utility.

---

## Features

Teacher chooses:

```txt
Visual Hierarchy
Gestalt
Color
Typography
Composition
```

Then enters:

```txt
Presentation Mode
```

Presentation Mode should:

- enlarge examples
- hide unnecessary navigation
- enlarge controls
- work with projector
- support keyboard navigation

---

## Suggested Flow

```txt
Definition
↓
Visual Example
↓
Question
↓
Interactive Demonstration
↓
Mini Challenge
```

---

## Difficulty

Allow:

```txt
Beginner
Intermediate
Advanced
```
