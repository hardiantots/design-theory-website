## Accessibility

Include text/background contrast checker.

Display:

```txt
Contrast Ratio
Normal Text
Large Text
```

Provide WCAG-oriented guidance where technically appropriate.

Do not reduce results to only:

```txt
Good / Bad
```

Explain readability consequences.

---

## Color Meaning

Avoid simplistic universal psychology.

Do NOT write:

> Blue means trust.

Prefer:

> Blue is often associated with calmness, reliability, or professionalism in some contexts, but meaning depends on culture, audience, surrounding colors, and context.

## Hierarchy Exercise

Start with:

```txt
Event Name
Date
Location
Description
Call to Action
```

All initially use equal visual weight.

Student creates:

```txt
Primary
Secondary
Tertiary
```

Do NOT enforce one exact numerical answer.

Provide observations instead.

---

## Font Pairing

Introduce:

```txt
Serif + Sans Serif
Superfamily
Display + Neutral Body
Single Family with Multiple Weights
```

Practical beginner guideline:

> Two font families are usually enough for a simple student project.

Explicitly explain that this is a guideline.
